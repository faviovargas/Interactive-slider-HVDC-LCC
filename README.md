# Simulador HVDC LCC

Simulador interactivo de operación de un enlace HVDC con convertidores conmutados por línea (LCC).

**Demo:** https://faviovargas.github.io/Interactive-slider-HVDC-LCC/

- Característica V–I del rectificador y el inversor (α<sub>min</sub>, γ<sub>0</sub>, margen de corriente)
- Esquema del enlace con valores en vivo
- Ángulos de disparo α y extinción γ sobre la forma de onda
- P, Q, V<sub>dc</sub> y modo de control de cada convertidor, en ambas direcciones de potencia

Es un único archivo HTML sin dependencias: abre `index.html` en el navegador.
La versión anterior de la interfaz está en `original.html`.
